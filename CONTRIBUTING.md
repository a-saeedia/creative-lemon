# Contributing

Small, focused pull requests are welcome.

## Before you open one

1. Search existing issues first.
2. Keep the diff to one concern; unrelated reformatting will be asked out.
3. Run whatever the README describes as the check/build step.

## Commits

Conventional Commits style: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`.

## Security

Never include credentials, tokens, or customer data in a commit, issue, or pull request.
Report vulnerabilities privately — see `SECURITY.md`.
